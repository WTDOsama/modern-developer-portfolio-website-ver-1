Who I am

I'm Alex Morgan, a self-taught web developer focused on front-end development. I enjoy turning ideas into clean, accessible interfaces and I care about writing code that other people can read and maintain.

What I am learning

Right now I'm going deeper into modern JavaScript (ES6+), React components and hooks, responsive layout systems with Flexbox and Grid, and version control with Git & GitHub.

My development journey

I started with static HTML and CSS pages, then added interactivity with JavaScript, and gradually moved towards component-based interfaces. Every project in this portfolio is a step in that journey — small, focused and built from scratch.

My career goals

My goal is to join a team where I can grow as a front-end developer, contribute to real products, keep learning best practices, and eventually mentor other beginners.
