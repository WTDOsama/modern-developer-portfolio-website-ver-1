# Personal Portfolio Website

موقع شخصي احترافي ومتجاوب لمطور ويب مبتدئ أو محترف.
تم بناء المشروع باستخدام HTML5 و CSS3 و JavaScript فقط، بدون React أو أي إطار عمل إضافي.

## محتويات المشروع

```text
portfolio-website/
├── index.html              # الهيكل الرئيسي لجميع أقسام الموقع
├── style.css               # جميع التنسيقات والثيمات المتجاوبة
├── script.js               # جميع الخصائص التفاعلية
├── images/
│   ├── profile.svg         # صورة الملف الشخصي المؤقتة
│   ├── project1.svg        # مشروع الطقس
│   ├── project2.svg        # مشروع المتجر الإلكتروني
│   ├── project3.svg        # مشروع الموقع الشخصي
│   ├── project4.svg        # مشروع إدارة المهام
│   └── project5.svg        # مشروع لوحة تحكم React
├── resume.pdf              # ضع ملف السيرة الذاتية الحقيقي هنا
└── README.md
```

الصور الحالية عبارة عن ملفات SVG خفيفة حتى يعمل الموقع مباشرة بدون ملفات ناقصة.
يمكن استبدالها بصورك الخاصة، ثم تعديل قيمة `src` و `alt` داخل `index.html`.

## الخصائص

- شريط تنقل ثابت ومتجاوب مع قائمة hamburger للموبايل.
- تمرير سلس بين أقسام الموقع.
- تفعيل رابط القسم الحالي أثناء التمرير.
- الوضع الفاتح والوضع الداكن مع حفظ الاختيار في `localStorage`.
- حركات ظهور تدريجية عند الوصول إلى الأقسام.
- أشرطة مهارات متحركة مع نسبة مئوية.
- تصفية المشاريع حسب التقنية: All و HTML/CSS و JavaScript و React.
- نموذج تواصل مع تحقق من الاسم والبريد والموضوع والرسالة.
- رسائل نجاح وأخطاء داخل الصفحة بدون استخدام `alert()`.
- زر للعودة إلى أعلى الصفحة.
- شاشة تحميل أولية.
- دعم أساسي لمحركات البحث و Open Graph.
- دعم لوحة المفاتيح وحالات التركيز والوصف البديل للصور.

## تشغيل المشروع

1. افتح مجلد المشروع.
2. شغل `index.html` مباشرة في المتصفح.
3. يفضل استخدام إضافة Live Server أثناء التطوير لتحديث الصفحة تلقائيا.

## التخصيص

1. ابحث عن `Alex Morgan` داخل `index.html` واستبدله باسمك في الشعار والواجهة والتذييل.
2. استبدل بيانات البريد والهاتف والموقع وروابط GitHub و LinkedIn.
3. عدل متغيرات الألوان في بداية ملف `style.css` مثل `--primary` و `--gradient`.
4. عدل المشاريع داخل عناصر `<article class="project">` وأضف روابط العرض والمستودع الحقيقية.
5. عند إضافة مشروع جديد، اجعل قيمة `data-category` مطابقة لقيمة زر التصفية.
6. عدل قيمة `data-level` داخل أشرطة المهارات لتناسب مستواك من 0 إلى 100.
7. استبدل ملفات SVG داخل مجلد `images` بصورك الشخصية وصور مشاريعك.
8. ضع ملفك الحقيقي باسم `resume.pdf` في المجلد الرئيسي للمشروع.

## السيرة الذاتية

روابط السيرة الذاتية تستخدم الملف `resume.pdf`.
إذا لم يكن الملف موجودا، يعرض الموقع رسالة واضحة وينشئ ملفا نصيا مؤقتا بدل إظهار رابط مكسور.
عند وضع ملف PDF الحقيقي في المجلد الرئيسي، ستعمل أزرار التحميل والعرض مع الملف الحقيقي.

## ربط نموذج التواصل بخادم

النموذج يعمل حاليا على مستوى المتصفح فقط، ويقوم بالتحقق من البيانات وتجهيزها دون إرسالها إلى خادم.
لربطه بخدمة حقيقية مثل Formspree أو EmailJS أو API خاص بك، عدل الدالة `submitMessage()` داخل ملف `script.js`.

## النشر

المشروع ثابت بالكامل ويمكن نشره على:

- GitHub Pages.
- Netlify.
- Vercel.

قبل النشر، استبدل الروابط الوهمية وحدث قيم `og:url` و `og:image` داخل `index.html`.
